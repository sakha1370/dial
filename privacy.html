Privacy policy for Dial

Effective November 8, 2026. Applies to Dial version 1.3.0 and later.

Dial is a Chrome extension that replaces the new tab page with a personal dashboard. It is published by the developer named on its Chrome Web Store page. This policy explains what information Dial handles, where it is stored and who receives it.

Summary

  • Dial has no user accounts, no developer-operated servers, no advertising and no analytics.
  • The developer never receives your shortcuts, to-do list, journal, goals, financial records, weight entries, city or anything else you enter.
  • Two features contact third-party services directly from your browser: the weather (Open-Meteo) and missing site icons (Google’s favicon service). Both are described below, and the icon look-up can be turned off.

1. Information you enter and where it is stored

Dial stores what you enter in Chrome’s extension storage:

  • Synced through your Chrome account, when Chrome Sync is on: shortcuts and folders, settings, your chosen city, countdowns, course progress, weight entries and financial obligations. Google transfers and stores this data as part of Chrome Sync, under Google’s privacy policy and your Chrome settings. If an item is too large for Sync, Dial keeps it on this device only and tells you.
  • Stored only on this device: your to-do list, journal, goals, useful-time history and timer, uploaded wallpaper, caches (weather and icons), automatic backups, and a short list of the days on which Dial was opened (used only to decide when to show a one-time review request).

Automatic backups. Before an update of the extension, and before you restore a backup, Dial keeps a copy of your records in this device’s extension storage (the newest three; the wallpaper image is not included). You can restore the latest copy from Settings → Data. These copies never leave the device. Reset deletes them.

Dial does not add its own encryption to this storage or to exported backup files. Anyone with access to your Chrome profile or to an exported backup file may be able to read them. Keep backup files somewhere private.

2. Services Dial contacts

  • Open-Meteo (open-meteo.com), for weather. Nothing is sent until you choose a city. Then the city name you type, and the coordinates of the place you pick, are sent to Open-Meteo’s geocoding and forecast services, along with normal connection data such as your IP address. Dial never uses your device’s location. Open-Meteo’s own terms and privacy policy apply.
  • Google’s favicon service (www.google.com and gstatic.com), for site icons. Dial first uses the icons Chrome already has. Only when Chrome has none does Dial send the shortcut’s domain name (for example, example.com, never the full address) to Google’s favicon service. You can turn this off in Settings → Data → “Look up missing site icons”. Google’s privacy policy applies.
  • Image addresses you choose. If you set a wallpaper from a web address, Dial loads the image from that address.
  • Websites you open from Dial receive the same information as any normal visit.
  • The Chrome Web Store. If you choose “Write a review” or open the help page’s review link, the store page opens in a new tab.
  • An optional uninstall survey. If the developer has published one, Chrome opens a short feedback page on Dial’s website when you uninstall Dial. Its address includes only Dial’s version number and interface language; nothing else is sent unless you choose to answer.

3. What Dial does not do

  • Dial does not sell or transfer user data to anyone, except as described above to provide its features.
  • Dial does not use or transfer data for advertising, profiling, credit-worthiness or lending.
  • Dial does not read your browsing history. It only shows icons for the shortcuts you add.
  • Dial does not access your location, and it does not run remote code: all of its program code is included in the extension package.

4. Permissions

  • storage: saves your dashboard data.
  • favicon: shows your shortcuts’ icons from Chrome’s own icon cache.
  • Access to www.google.com and gstatic.com: downloads icon images for your shortcuts from Google’s favicon service when Chrome has none (can be turned off in Settings).

5. Your controls

  • Export: Settings → Data → Export saves a backup file of your Dial data.
  • Restore: Settings → Data → Restore, or restore the latest automatic backup.
  • Delete: Settings → Data → Reset deletes Dial’s data, including automatic backups, from this browser and from Chrome Sync. Uninstalling Dial removes its storage from this browser; to remove synced data everywhere, use Reset before uninstalling.
  • Icons: turn off “Look up missing site icons” to keep every icon request on your device.

6. Children

Dial is a general-audience tool. The developer does not collect information from anyone, including children.

7. Limited Use

Dial’s use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

8. Changes

Changes to this policy will be posted here with a new effective date. If Dial’s data practices change, Dial will tell you inside the extension before the change takes effect.
